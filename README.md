# Cloud DevOps Platform

## Project Status
Work in progress

## Project Purpose
This project is part of my journey back into DevOps and Cloud Engineering. It focuses on Linux automation, operational monitoring, logging, and future AWS deployment.

## Current Features
- Linux folder structure for DevOps project
- Shell scripts for system health checks
- Disk usage alerting
- Operational monitoring script
- Log file generation
- Git and GitHub version control

## Tools Used

- Git Bash

## Scripts

- disk-alert.sh: checks disk usage and writes alerts
